# DaoRing · 周天破境录

修仙题材的「同心圆阵盘构筑 + 算分生存」网页肉鸽游戏。把道韵卡牌布在丹田外的同心圆阵眼上，运转周天时，一股能量顺时针流经各个阵眼，被沿途道韵改变气势，最后由释放道韵化作万剑诀或灵爆术攻向敌人。单次产气破开护体魔光即斩敌晋升；真气耗尽、付不起下一次运转，就身死道消。

## 两种模式

| 入口 | 模式 | 内容 |
| --- | --- | --- |
| `index.html` | 炼气篇教学关 | 四槽内环、固定开局与引导，约 2–5 分钟 |
| `battle.html` | 斗法（正式模式） | 国漫风斗法场景，炼气 → 筑基 → 金丹 → 元婴 → 化神共 15 战，五层同心环、灵宝、天劫、炼化、功德 |

教学关顶栏的 ⚔ 按钮和通关弹窗都可以进入斗法。

## 快速开始

```bash
npm install
npm run dev        # 开发服务器 http://127.0.0.1:5173/ ，斗法模式访问 /battle.html
npm test           # 单元与流程测试（vitest）
npm run build      # tsc 严格类型检查 + Vite 构建（多页面，输出到 dist/）
npm run preview    # 预览构建结果
npm run balance    # 平衡性模拟：贪心机器人整局对打，打印每关通过率
```

## 玩法要点

- **能量流转**：每次运转，一股能量（基础气 10、倍率 1、步数 12）从第一眼 · 入气出发顺时针流动。走满一圈且外环已解锁时自动升环；遇到释放道韵出手，产气 = 基础气 × 倍率 × 释放系数。
- **道韵**：传导类（分光、升维、逆流）、增幅类（聚灵、锋芒、周天）、释放类（灵爆术、万剑诀），各有 LV1–5。
- **布阵代价**：空眼落子耗 1 张；覆盖已有道韵要再烧 1 张作燃料；拆除、移位也要烧 1 张。
- **炼化**：3 张同名同级道韵三合一；或 2 张同名同级加 1 张任意牌作催化剂精炼。
- **连携与共鸣**：增幅接增幅、传导接传导、增幅直入释放都有加成；同一环全是同类道韵时触发共鸣 ×1.25。
- **境界**：每个大境界 3 战。突破解锁新的一环，并三选一认主一件灵宝；每个巅峰之战降下天劫（神雷 / 心魔 / 祥云）。
- **局外成长**：每局结束结算功德，写入本地档案，用于局外天赋。

## 设计原则

- **数据与逻辑解耦**：数值全部来自 `src/data/*.json`。
- **演出只读引擎日志**：斗法画面完全按引擎的结算记录播放，不自带规则；每束释放的伤害就是日志里的 `qiDelta`，合计等于本回合产气。`tests/battle.test.ts` 用 600 个随机阵盘校验这一点。
